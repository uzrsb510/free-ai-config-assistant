# دستیار کانفیگ‌ساز رایگان

دستیار هوش مصنوعی فارسی با رابط کاربری راست‌چین.

## امکانات

- رابط کاربری فارسی
- ورود و ساخت حساب اولیه
- ذخیره نشست ورود
- تغییر رمز عبور
- تاریخچه گفت‌وگوها
- آپلود فایل
- اتصال قابل تنظیم به API هوش مصنوعی

## نصب

Node.js نسخه 20 یا جدیدتر لازم است.

```bash
npm install
npm start
